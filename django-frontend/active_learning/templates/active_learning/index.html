How It Works

Active Learning + LLM Synergy:

  1. The system selects the most informative instances using uncertainty sampling
  2. Instead of manual labeling, an LLM (via Langchain) labels these instances
  3. The Naive Bayes classifier learns from LLM-labeled data
  4. Feature labeling also uses LLM to identify discriminative terms
  5. This hybrid approach reduces LLM inference costs while maintaining high accuracy
