About Evaluation

This evaluation tests the model on the remaining unlabeled pool using their hidden true labels. In a real deployment, you would evaluate on a separate held-out test set.

Metrics Explained:

  • Accuracy: Percentage of correct predictions
  • Precision: Of predicted positives, how many are correct
  • Recall: Of actual positives, how many are found
  • F1: Harmonic mean of precision and recall
  • Macro F1: Average F1 across all classes (equal weight)
  • Weighted F1: Average F1 weighted by class frequency
