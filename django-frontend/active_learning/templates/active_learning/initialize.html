Pipeline Descriptions

Document Pipeline

Use for: Full documents, articles, reviews

Features: Unigrams (single words), HTML removal, lowercase, stopword filtering

Example: Movie reviews, news articles, product descriptions

Lines Pipeline

Use for: Short texts, sentences, line-by-line data

Features: Unigrams + bigrams, no stopword removal

Example: Search queries, short messages, survey responses

Twitter Pipeline

Use for: Social media posts, tweets, informal text

Features: Emoticons, @mentions, #hashtags, negation handling, bigrams

Example: Tweet sentiment, social media monitoring

Entity Pipeline

Use for: Named entity classification

Features: Orthographic patterns, shape features, character types, affixes

Example: Person/Organization/Location classification
